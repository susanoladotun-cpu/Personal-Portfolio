# Portfolio-Landing-Page
Personal portfolio website built with HTML5, CSS3, and modern JavaScript.

A clean, modern and fully responsive personal portfolio website build with standard web technologies. Clean user interface highlighting full-stack development projects, technical skills and professional experience.

---

## 🌟 Key Features

- **Multi-Page Navigation:** Dedicated pages for Home, About, Projects and Contact
- **Responsive Layout:** Flexible grid layout with dynamic navigation menu, optimised for mobile, tablet and desktop screens.
- **Interactive Project Showcase:** It features category filtering and detailed dynamic modal popups for thorough investigation of individual projects.
- **Contact Form Feedback:** Interactive UI with feedback toast notifications on form interaction.
- **Modern UI Styling:** Built with modern CSS, custom colour gradients, FontAwesome icons and Google Fonts typography.
